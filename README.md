# 🧮 Calculator

A simple and user-friendly calculator web application built using **HTML, CSS, and JavaScript**.

## 📌 Project Description

This project is a basic calculator that performs common arithmetic operations such as:

- Addition (+)
- Subtraction (−)
- Multiplication (×)
- Division (÷)
- Percentage (%)
- Decimal calculations
- Clear (C)
- Delete (⌫)

The calculator has a clean and responsive interface that makes it easy to perform calculations.

## 🚀 Features

- Simple and attractive user interface
- Basic arithmetic operations
- Clear button to reset the calculator
- Delete button to remove the last entered value
- Percentage calculation
- Decimal number support
- Interactive buttons with hover effects
- JavaScript-based calculation functionality

## 🛠️ Technologies Used

- **HTML5** – Structure of the calculator
- **CSS3** – Styling and layout
- **JavaScript** – Calculator functionality
